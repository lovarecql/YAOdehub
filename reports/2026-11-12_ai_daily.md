# 每日AI前沿简报

## 📄 论文亮点

### 1. 医学图像分割：基础模型适配 vs 任务特定训练
**核心创新**：用 DINOv2 系统对比“基础模型适配”与“从零训练 U-Net/ResU-Net”在医学分割上的真实表现，覆盖结肠镜、乳腺超声、皮肤镜三类数据。
**技术突破**：适配策略从仅调 bias 到全量微调；关键发现是**适配后的基础模型在所有外部机构数据集上泛化更优**，而分布内任务特定模型在数据充足时仍具竞争力、边界更精细；基础模型更易漏检小病灶；仅需极少量参数适配即可获得大部收益。
🔗 http://arxiv.org/abs/2611.14519v1

### 2. 面向基础检测模型的 EM-DETR 示例驱动 Grounding
**核心创新**：构建多域医学病灶检测基础模型，将异构标注（解剖结构 + 异常）数据集统一训练。
**技术突破**：提出**师生训练策略**融合异构标签空间、缓解灾难性遗忘；扩展示例驱动的 EM-DETR 支持跨模态联合学习；在 CXR 四项关键发现上 AUC 超此前 SOTA 1 个百分点，CXR 与乳腺摄影取得领先 mAP50。
🔗 http://arxiv.org/abs/2611.14518v1

### 3. TorchCurves：可微参数曲线库
**核心创新**：将 B 样条 / Legendre 多项式表示的参数曲线作为 PyTorch 可学习原语，支持对输入与系数同时求导。
**技术突破**：提供可训练模块、可复用基模块与函数式接口；可用于连续特征嵌入、Kolmogorov-Arnold 网络（KAN）与函数回归；纯向量化实现、无自定义硬件核，并给出与 NumPy/SciPy、EfficientKAN 的计时对比。
🔗 http://arxiv.org/abs/2611.14516v1

### 4. AutoScaffold：AI 自引导的语言模型强化学习脚手架
**核心创新**：解决 RLVR “结果奖励压成单标量、信息浪费”的问题——用冻结教师模型诊断学生训练经验瓶颈，自动生成脚手架。
**技术突破**：脚手架分两类：**跨任务共享策略**与**难题专属提示**，随学习进度动态调整内容与强度，评估时完全移除；在 ALFWorld、搜索问答、数学推理、GPU kernel 生成上均超越对应 RL 基线，且无需领域知识、训练中无人工干预。
🔗 http://arxiv.org/abs/2611.14515v1

### 5. Contrastive Discovery：竞争性解释上的开放式科学发现
**核心创新**：指出现有 LLM 科学发现 agent 逐点检验 *h* vs *¬h* 的缺陷——拒绝假设后不知道哪个替代解释成立。
**技术突破**：引入**对比集**（一个科学问题 + 互斥且穷尽的竞争解释），以证据对信念分布的重分配程度评分；实验显示 89% 逐点最大信念偏移是“拒绝”，对比集可将其中 73% 解析到具体替代解释；引导搜索时比逐点惊讶度多解决 67% 问题，覆盖六个领域。
🔗 http://arxiv.org/abs/2611.14514v1

### 6. Pyrite：蛋白-配体构象排序 Agent 的构建与基准
**核心创新**：发布 1,500 对蛋白-配体构象的成对排序基准；发现配备 3D 可视化与物理评分的**专家化学家仅接近随机**。
**技术突破**：提出结构化表示 PyriteRep（几何 + 相互作用 + 理化评分）；PyriteReasoner（文本推理）与 PyriteFeaturizer（生成代码构建特征 + 逻辑回归）分别达 67% / 74% 准确率，超专家表现；LLM 引导特征发现优于直接推理，GRPO 可提升开源模型。
🔗 http://arxiv.org/abs/2611.14511v1

### 7. 真实连接何时胜出？检验连接组结构-功能主张
**核心创新**：揭示连接组建模中的混淆偏差——真实连接胜出可能只是“模型参数被调到能工作”，而非结构本身贡献。
**技术突破**：分离三类估计量（P1 真实连接调参迁移到零模型、P2 各自调参、P3 限定与独立生理数据一致）；用合成真值、安慰剂零模型与三个果蝇回路量化偏差。结论：部分主张稳健（奖赏/惩罚多巴胺分离、头方向拓扑），部分反转（蘑菇体 Kenyon 细胞输出连接在 P1/P2 下胜 0.09，P3 下反负 0.09）。
🔗 http://arxiv.org/abs/2611.14508v1

### 8. Continual-ARC：衡量工作生命周期内的技能习得
**核心创新**：针对持续学习基准“单领域、实例一次性、单一学习器家族”的三大局限，构建基于三代 ARC-AGI 的终身任务流（无需领域知识）。
**技术突破**：同一任务隔休眠期以新实例回归、新任务持续到来；学习者可付费购买演示、提交答案或 harness 内行动，按**反馈预算消耗比例**计分；实例间可任意保留状态，使**记忆型与权重型学习器同尺度比较**；流结束后冻结并分别在已见任务新实例（记忆）与未见任务（泛化）上测试。
🔗 http://arxiv.org/abs/2611.14505v1

## 💡 简短点评

1. **医学分割对比**：价值在于打破“基础模型必然全面替代任务模型”的叙事，给出跨机构泛化的实证。局限是仅评估 DINOv2 与两类 CNN；小病灶漏检是临床落地隐患。应用方向：多中心部署前的模型选型与适配预算评估。

2. **EM-DETR 基础检测**：师生策略处理异构标签空间是医学检测数据碎片化的务实解法。局限是示例驱动依赖参考示例质量、跨模态扩展成本高。应用：CAD 系统跨解剖域冷启动。

3. **TorchCurves**：填补 PyTorch 缺少原生可微曲线原语的空白，对 KAN 与连续隐表示研究友好。局限是无定制核导致规模上去后开销显著，定位偏原型验证而非大规模训练。应用：连续嵌入、函数回归、KAN 教学与研究。

4. **AutoScaffold**：把 RLVR 的“过程信息”再利用，思路通用且无需人工设计脚手架，跨四类任务一致增益是强证据。局限是学生可能“套用策略”而非真正习得、脚手架移除后性能依赖教师质量。应用：通用 RL 后训练流程的即插即用增强。

5. **Contrastive Discovery**：把科学发现从“假设检验”重构为“模型比较”，与贝叶斯实验设计思想一致，67% 的搜索效率提升有说服力。局限是构造互斥穷尽解释集本身需领域知识，LLM 能否保证 MEE 性存疑。应用：自动化实验设计、假设空间排序。

6. **Pyrite**：专家近随机这一结果本身就是重要发现，说明现有化学信号难以人工整合；LLM 特征工程 > 直接推理也具方法论价值。局限是 1,500 对规模有限、成对设置与真实排序场景有差距。应用：共折叠模型的构象重排序、虚拟筛选。

7. **连接组方法学批判**：对计算神经科学“结构决定功能”的论证实践是一次必要的方法论纠偏，P1/P2/P3 框架可直接复用。局限是仅验三个果蝇回路、合成真值设定影响结论外推。应用：连接组约束建模的基准规范、ML 中“调参公平性”评估。

8. **Continual-ARC**：反馈预算计分 + 记忆/权重同尺度比较是持续学习评测的实质性改进，休眠期回归设计贴近真实工作场景。局限是 ARC 任务偏抽象推理、付费重试机制可能引入预算策略博弈。应用：终身学习 agent harness 的标准化评测。
