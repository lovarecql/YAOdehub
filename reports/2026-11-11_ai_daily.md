# 每日AI前沿简报

## 📄 论文亮点

1. **[Medical Image Segmentation: Foundation Model Adaptation versus Task-Specific Training](http://arxiv.org/abs/2611.14519v1)**  
   - 核心：系统比较 DINOv2 基础模型从“仅调 bias”到“全微调”的多级适配策略，并与从头训练的 U-Net/ResU-Net 对比。  
   - 突破：在结肠镜、乳腺超声、皮肤镜及跨机构外部数据上，适配后的基础模型外部泛化均更优；但分布内数据充足时任务专用模型仍有竞争力、边界更精确，基础模型更易漏小病灶；初步显示仅少量参数适配即可获得优势。

2. **[Toward Foundation Detection Models via Example-Based Grounding in EM-DETR](http://arxiv.org/abs/2611.14518v1)**  
   - 核心：整合多模态医学数据中解剖结构与异常标注，构建面向病灶检测的多域基础模型；采用学生-教师训练缓解异质标签空间下的灾难性遗忘。  
   - 突破：将示例驱动的 EM-DETR 扩展到多域联合学习，实现跨模态细粒度检测；在胸片四个关键发现上图像级 AUC 较此前 SOTA 提升约 1 个百分点，并在胸片和乳腺摄影 mAP50 上领先。

3. **[TorchCurves: Differentiable Parametric Curves](http://arxiv.org/abs/2611.14516v1)**  
   - 核心：提出 PyTorch 可微参数曲线库，将 B-spline/Legendre 多项式基曲线作为可学习原语，支持对输入和曲线系数同时求导。  
   - 突破：提供可训练模块、可复用基模块和函数式接口，可服务连续特征嵌入、Kolmogorov-Arnold 网络与函数回归；以向量化 PyTorch 实现兼顾可读性，并系统比较曲线求值与 KAN 训练开销。

4. **[AutoScaffold: AI-Guided Scaffolding for Reinforcement Learning of Language Models](http://arxiv.org/abs/2611.14515v1)**  
   - 核心：利用冻结教师模型周期性诊断学生训练经验，自动生成跨任务策略与难题提示两类训练脚手架，并随学习进度调整支持强度；评估时移除脚手架。  
   - 突破：将 RLVR 中未被结果奖励利用的过程信息转化为自适应训练信号，减少人工领域设计；在 ALFWorld、搜索问答、数学推理和 GPU kernel 生成中，无脚手架评估时优于对应 RL 基线。

5. **[Contrastive Discovery: Open-Ended Scientific Discovery over Competing Explanations](http://arxiv.org/abs/2611.14514v1)**  
   - 核心：用“对比集”替代单假设检验，即科学问题配套互斥且完备的竞争解释，按实验证据在解释集合上的信念重分配来评分与决策。  
   - 突破：现有 LLM 科学发现 agent 可复用该单元重新评估已有证据或指导搜索；六领域中 89% 最大信念偏移的点式候选是拒绝，而对比集在同证据下将其中 73% 解析为具体替代，搜索引导时比点式 surprisal 多解决 67% 问题。

6. **[Pyrite: Building and Benchmarking Protein-Ligand Pose Ranking Agents](http://arxiv.org/abs/2611.14511v1)**  
   - 核心：构建 1500 对蛋白-配体姿态的成对排序基准 Pyrite，并提供结构化表示 PyriteRep；开发文本推理型 PyriteReasoner 与代码生成特征型 PyriteFeaturizer 两类 LLM agent。  
   - 突破：专家借助 3D 可视化和物理分数仍接近随机，而两类 agent 分别达到最高 67% 和 74% 准确率；LLM 引导特征发现通常优于直接推理，GRPO 可提升开源模型表现。

7. **[When Does the Real Wiring Win? Testing connectome structure-function claims against unmeasured physiology](http://arxiv.org/abs/2611.14508v1)**  
   - 核心：指出连接组约束模型常将“真实布线优势”与调参偏倚混淆，提出 P1/P2/P3 三个估计量，分别控制生理参数迁移、各布线独立调参及独立数据一致性约束。  
   - 突破：用合成真值、安慰剂 null 和三个果蝇电路模型量化欠调基线、继承权重、winner’s curse 对生物结论的影响；部分结论稳健，如奖赏/惩罚多巴胺分离改善学习、头方向地形支持持续 bump，但蘑菇体输出布线优势在 P3 下反转。

8. **[Continual-ARC: Measuring Skill Acquisition over a Working Lifetime](http://arxiv.org/abs/2611.14505v1)**  
   - 核心：基于三版 ARC-AGI 构建终生学习流，任务在休眠间隔后以新实例重现，新任务持续到达；学习器需在反馈预算内购买演示、提交答案或执行动作。  
   - 突破：按预算消耗评分，并允许跨实例保留任意信息，使记忆型与权重型学习器可在同一尺度比较；流结束后冻结模型，分别测试已见任务新实例的记忆能力与未见任务的泛化能力。

## 💡 简短点评

1. **医学分割基础模型 vs 任务专用模型**：价值在于用跨机构外部数据检验泛化，而非只看同分布精度；局限是基础模型小病灶召回和边界精度仍不足；适合临床跨中心部署前的轻量适配评估。
2. **EM-DETR 多域检测基础模型**：价值在于缓解医学检测标注稀缺与标签异构，示例驱动思路利于跨模态迁移；局限是仍需更多模态和标签噪声场景验证；可用于多病种 CAD 筛查。
3. **TorchCurves**：价值是降低可微参数曲线与 KAN 相关研究的工程门槛；局限是无自定义硬件 kernel，较大规模下开销明显；适合连续表示、函数回归和科学计算原型。
4. **AutoScaffold**：价值是自动把 RL 训练经验转化为自适应课程，跨领域通用且评估时去脚手架；局限是依赖冻结教师诊断质量，需警惕脚手架过拟合；可用于 LLM 推理、代码生成和复杂 agent 训练。
5. **Contrastive Discovery**：价值是让科学发现 agent 从“拒绝假设”走向“定位替代解释”，提高证据利用率和可解释性；局限是需构建高质量互斥完备解释集；适合假设驱动实验设计与自动科研。
6. **Pyrite**：价值是提出贴近药物发现需求的成对姿态排序基准，并展示 LLM 特征工程潜力；局限是专家近随机提示任务信号或评估设计仍需审视；可用于共折叠候选姿态筛选与药物先导优化。
7. **连接组结构-功能审计**：价值是揭示计算神经模型中调参偏倚如何影响生物结论，方法学意义强；局限是结论依赖模型保真度与独立生理数据质量；适合连接组约束模型的可复现评估。
8. **Continual-ARC**：价值是将记忆型与权重型持续学习系统放到统一终生预算框架下比较，并区分记忆与泛化；局限是 ARC 任务和预算设计可能限制外推；可用于长期运行 agent 的技能获得评测。
