### 1. Text-to-Image Generative Modeling Without Language Pretraining
🔗 http://arxiv.org/abs/2610.26863v1

- **核心问题**：直接质疑主流 T2I 系统“必须依赖互联网规模语言预训练”的默认假设。
- **方法**：提出 **Halcyon** 系列早期融合（early-fusion）多模态自回归模型，在 **GPIC**（1 亿图文对）上**完全从零预训练**，不使用语言模型初始化。
- **关键结论**：受控实验显示**纯文本预训练并不提升 T2I 生成质量**；文本条件能力可直接从图文联合预训练中获得。
- **效率突破**：Halcyon-0.52B 在 gFD 指标上优于 LlamaGen-XL/8（48.0 vs 63.3），预训练算力仅 1/18.2；Halcyon-1.6B 优于 JiT-T2I-XXL/8++（35.3 vs 41.0），算力仅 1/275。
- **附加发现**：将 caption dropout 替换为 **I2T 监督**即可获得图像描述能力，同等预算下 T2I 质量不受损。

💡 **点评**：这是对“语言预训练不可或缺”论的一次清晰的反例验证，把 T2I 的算力开销从“千亿 token 语言语料”拉回到图文对本身，对算力受限团队、非英语语种与垂直领域生成模型有直接意义。局限在于仍依赖 1 亿级图文对、单一自回归范式，且 gFD 等感知指标难以覆盖组合推理、长提示与文字渲染等语言强相关能力；后续需要在这些维度上证明“无语言预训练”不掉队。

### 2. OpenVLHarness: Real World Visual Agentic Tool-Use with Multimodal Memory
🔗 http://arxiv.org/abs/2610.26860v1

- **动机实验**：在 **22 个基准**上的受控研究表明，单纯增加基座 MLLM 的推理预算只能带来有限增益，许多任务所需证据无法通过内部推理获得。
- **系统设计**：提出多模态推理 harness，由两层构成——
  - **能力层**：任务级工具接口 + 证据渲染（evidence rendering），统一封装异构后端，并将其输出转换为模型可读的观察；
  - **持久多模态记忆**：图像、结构化数据、网页引用作为**可寻址产物（addressable artifacts）**，在整条查询链路中留存。
- **计算接口**：代码接口可在已存储数据上执行生成程序，从而组合多个工具结果完成数值计算，支撑迭代式证据获取。

💡 **点评**：把“工具调用”从提示词技巧提升为**系统级 harness + 记忆架构**，切中了 agent 的真实瓶颈：证据的获得、表征与跨步骤保持。价值在于可复用的 agentic 基础设施；局限是工程复杂度高、强依赖工具集的覆盖与稳定性，长程迭代中的错误累积与推理延迟/成本未被充分讨论。（摘要截断，详细评测结果待阅全文）

### 3. Can It Actually Work? Synthesizing Functional CAD Mechanisms
🔗 http://arxiv.org/abs/2610.26861v1

- **问题**：LLM agent 能生成视觉上合理的 CAD 装配，但常**无法实现预期物理功能**。
- **任务定义**：提出 **functional CAD design**——从欠规约（underspecified）需求出发，构建并迭代修改机构，使其在物理仿真中满足功能要求。
- **核心难点**：同一功能可由完全不同的零件、控制与操作时序实现，因此验证方式不能通用。
- **方法**：**FunCAD-Harness** 将抽象需求翻译为**候选方案特定的物理测试**，用仿真反馈驱动设计修订。
- **基准**：**FunCADBench**，覆盖 **46 个机构族**，含相互依赖的多步操作。实验显示该框架能暴露视觉检查完全不可见的细微机械失效，功能成功率显著高于标准“仿真增强”基线。

💡 **点评**：把 CAD agent 的评价标准从“看起来对”推进到“跑起来对”，是 benchmark 与 harness 的双重贡献，“需求→候选特定测试”的思路可迁移到其他可仿真验证的生成任务。局限在于物理仿真的保真度鸿沟、机构族覆盖仍有边界、迭代搜索成本较高；应用面直指机构设计、机电原型与 CAD Copilot。

### 4. Reinforcement Learning with Visually Attributable On-Policy Self-Distillation
🔗 http://arxiv.org/abs/2610.26856v1

- **问题诊断**：多模态 RLVR 只提供任务级奖励，难以定位视觉推理的错误来源；on-policy self-distillation（OPSD）虽提供 token 级稠密纠正，但特权教师（带证据中心视觉视图）给出的纠正可能**混入语言先验、回答风格、特权视角本身**的非视觉偏移。
- **概念化**：将上述现象形式化为 **privileged-correction contamination（特权纠正污染）**——当某 token 级更新方向无法一致归因于特权视觉证据时即视为受污染，直接蒸馏会强化错误更新。
- **方法**：提出以**视觉可归因**为准则的 RL 范式，实例化为 **Visual-Attribution Gating（VAG）**，以验证器导出的 advantage 作为优化信号，对 token 级纠正做证据一致性门控，与任务级 RLVR 监督互补。

💡 **点评**：这是自蒸馏/RLVR 交叉方向上一处较细粒度但切中要害的诊断：把“特权信息”中的混杂因素显式建模而非盲目蒸馏。局限是需要特权视图与可靠验证器，门控策略也可能过滤掉部分有益信号；潜在应用集中在图表理解、文档、几何等**需要精确定位视觉证据**的多模态推理任务。

### 5. VideoMaMa++: Temporally Consistent Video Matting via Preserve-and-Refine Token
🔗 http://arxiv.org/abs/2610.26857v1

- **痛点**：扩散式视频抠像受显存限制，单次仅能处理 6–24 帧，各块独立抠像导致**块边界闪烁、透明度不连续**。
- **架构创新**：将 **RGB 与 mask 条件表示为两条独立 token 流**，通过完整的时空自注意力交互，自适应融合细粒度 RGB 纹理与粗粒度 mask 布局，取代固定通道拼接式融合。
- **推理机制**：引入一对可学习嵌入——**preserve token** 与 **refine token**，作为逐帧条件接口，实现**滑动窗口推理**，把已生成的 matte 跨块传播并在局部细化。

💡 **点评**：把长视频一致性从“后处理修补”变成**推理机制的一部分**，RGB/mask 解耦 + 记忆型 token 是可复用到其他长视频生成任务的通用设计。局限在于仍依赖扩散骨干的算力、极端运动与遮挡场景、以及合成训练数据的域偏移；应用直指影视后期、虚拟制作、AR 合成与高质量数据标注。

### 6. Ropedia W0: Scaling Loco-Manipulation World Models across Embodiments with Human Experience
🔗 http://arxiv.org/abs/2610.26855v1

- **定位**：首个覆盖**人类与多种形态机器人**的自我中心（egocentric）移动-操作（loco-manipulation）世界基础模型。
- **数据**：**Xp-Data** = 1 万小时自我中心人类视频 + 3 千小时机器人数据，统一多模态标注与系统化质量控制。
- **统一表征**：用**相机位姿**编码 locomotion、用**投影骨架**编码 manipulation；机器人骨架结合 embodiment-specific 前向运动学与大量人工关键点标注校正，从而对齐异构动作空间。
- **基准**：**Xp-Teleop**，基于高质量灵巧人形遥操作数据的长程 loco-manipulation 评测。
- **结果**：在 DreamDojo、Ψ₀、ω-HOME、Xp-Teleop、AgiBot 五个跨形态基准及留出人类自我中心视频上达 SOTA，覆盖零样本、少样本与全量后训练；人类预训练数据规模扩展带来稳定收益。

💡 **点评**：在具身基础模型中，“人类数据→机器人策略”的迁移与跨形态动作空间对齐是最硬的瓶颈，本工作以统一运动学表征 + 大规模人工校正数据正面攻克，**数据引擎价值可能高于模型本身**。局限是运动学层面的统一会损失动力学与接触细节、遥操作数据存在操作者偏置，且以离线/仿真指标为主；应用指向人形机器人策略预训练、遥操作增强与通用数据生产管线。

### 7. InfiniDream: Open-Ended Photorealistic 3D Worlds Through Procedural Generation
🔗 http://arxiv.org/abs/2610.26853v1

- **背景矛盾**：程序化生成可控、可编辑、多样化，但需大量人工开发；VLM 直接写代码只能产出**较简单的 3D 资产**，而现有 VLM 引导的程序化流程被**预定义 factory/API** 锁死，无法生成新资产类型。
- **技术一**：**Symbolically Constrained Asset Generation**——在既有程序化算法上施加符号约束，生成**新颖、照片级真实**且保持可编辑性与种子级多样性的资产。
- **技术二**：端到端 text-to-world 管线，结合语义场景规划与 **Deterministic Frustum-Guided Grid Placement**，实现大规模 3D 世界的精确物体摆放、程序化填充与动画。
- **评测**：100 个物体 + 20 个场景任务，四项感知指标全面提升，并给出多样性分析与消融。

💡 **点评**：关键洞察是把 VLM 从“自由写代码”降级为“在结构化程序空间中受约束地选择与组合”，既规避代码生成的脆弱性，又保留程序化资产的**可编辑、可复现（seed）**优势。局限是能力上限受底层程序化资产库覆盖度约束、“照片级真实”仍高度依赖材质与光照，且评测以感知指标为主、缺少下游任务闭环；应用面覆盖游戏关卡生成、合成数据生产与机器人仿真场景构建。

### 8. CoopUQ: Robust Multi-Robot Social Navigation via Uncertainty-Aware Cooperative Forecasting
🔗 http://arxiv.org/abs/2610.26852v1

- **问题**：单机 RL 直接扩展到多机器人社会导航，在遮挡与 OOD 场景下安全性与效率双双退化，个体机器人易忽略潜在风险。
- **预测端**：通过**跨机器人时空特征融合**预测未来占据栅格（occupancy grid）。
- **决策端**：将预测结果**及其不确定性**接入**约束式多智能体 RL**，以 cost 惩罚进入“预测被占据或高不确定”区域的导航行为，使策略的风险敏感度可随分布漂移自适应调整。
- **验证**：多个 Unity3D 仿真环境，覆盖同分布与 OOD 设定及多样布局。

💡 **点评**：把“预测不确定性”直接变成约束式 MARL 的代价项，是很自然且说服力强的耦合设计，比事后避障更符合风险意识导航的本意。局限是仍以仿真为主、多机通信与感知共享假设较强、真实人群行为多样性未被覆盖；应用指向仓储 AMR 车队、医院/商场服务机器人与园区低速自动驾驶。

## 🧭 今日观察

1. **“预训练必要性”被重新审视**：Halcyon 用受控实验否定了“语言预训练是 T2I 必要条件”，与近期从零训练多模态模型的趋势一致——**数据域匹配度可能比预训练规模更关键**。
2. **Agent 基础设施成为主战场**：OpenVLHarness（工具+记忆）、FunCAD-Harness（仿真验证）、CoopUQ（不确定性耦合）共同显示，性能提升正从“更大模型/更多推理 token”转向**外部证据与验证闭环的系统设计**。
3. **可验证性成为新的评测货币**：FunCADBench 与 Xp-Teleop 都不再以视觉保真度为终点，而是要求**物理可执行 / 功能可达成**，这将是 2026 年 agent 评测的主要演进方向。
